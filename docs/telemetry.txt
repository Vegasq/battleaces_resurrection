PURE TRANSFORMATION AND COMPONENT IDENTITY

client_patch/patcher/telemetry.py exposes:
 patch_component(exact_game_relative_path, original_bytes) -> patched_bytes
It validates the entire original SHA-256, every short instruction guard, bounds
and non-overlap before producing an equal-length copy. Unknown paths, aliases,
already-patched files and partially modified input are rejected. The function
performs no I/O, changes no input bytes and preserves all unrelated bytes.
