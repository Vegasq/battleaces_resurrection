Player experience
Extract the client patch ZIP and double-click Setup Client.cmd (or Start Client.cmd
on first use). Choose the working game folder,set a player name,enter the server
IP,and click Install / Update. No CA file,fingerprint,certificate name,invite,
Python install or developer tools. Server port47623 is the default;advanced
server_host/server_port/display_name remain editable in config/client.json.
Blank address is valid for offline play. Thereafter use Start Client.cmd.
Install/update verifies supported local files,preserves original backups and saves.
Restore original is available in the same setup window. No game assets ship in Git.

RC connection contract
Schema4 selects RC open access and TLS encryption WITHOUT certificate verification.
The server automatically generates its own self-signed certificate on first start
after assets are imported. Players never handle it. RC open access admits anyone
who can reach the configured server;it is not an invite allowlist or verified
server identity. A local per-server/profile random key gives stable player identity
on reconnect;names are configurable independently. Local profile saves persist.
Existing schema2/3 verified CA/invite deployments remain explicit supported paths;
they are not silently converted on launch and never fall back to open admission.
Saving from the new RC setup explicitly selects schema4 and preserves local_profile.
No plaintext fallback,OS trust-store edit,firewall edit or router configuration.
