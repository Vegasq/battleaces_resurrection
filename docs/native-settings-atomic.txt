  precommit. Verify owner/group/DACL/inheritance match the sibling's inherited
  permissions. A customized mismatch refuses saving;no permission-edit rights
  or automatic permission changes are needed. This does not preserve every
  alternate stream,attribute,SACL or custom file metadata policy.
- Flush the completed native output,release the old-target validation handle,
  then publish through SetFileInformationByHandle(FileRenameInfo) on the pinned
  source handle. The separate profile writer lock stays held. A previously
  absent destination uses ReplaceIfExists=false. Never delete/truncate target
  as a preliminary operation. Only the complete publication returns success.

  cleanup failure or process termination can leave a ba-*.tmp sibling. Startup
  ignores these files and never imports/deletes them automatically. Canonical
  settings remain the only input;later saves choose a fresh temporary name.
- Existing deferred native warning/retry uses the aggregate final result.
  Ordinary play receives no automatic action,capture or acknowledgment.
