separate practice coordinator. It snapshots the current valid eight-unit deck
and four abilities, selects the primary shipped mode4 map and an intact AI profile, and
copies the profile's first shipped character deck. Selecting the first choice
is our policy; the retired server's map/deck randomness is not recovered.
No extracted decks, maps, tuning assets or original binaries belong in Git.

The first prototype used Easy17; standalone practice defaults to Normal18 after
the movement qualification below. The selected profile supplies native bot
behavior/fuzzy tuning. The original prototype preserved static army modifiers.
The later Settings selector now applies an explicit offline community difficulty
policy: Easy uses Normal tactics with authored Easy strength, Normal stays at
baseline, and Hard applies authored Hard strength. See practice-difficulty.txt
for UI persistence, modifier mapping and separate native qualification. This is
not a reconstruction of retired-server rating policy. A fresh zero-valued
ArmyModifiers object is not a neutral multiplier and must not be fabricated.

The human and AI retain separate GameServerIntegration instances and identities.
The local loop combines their queues into one ordered 20Hz input stream for one
human-owned simulation. The exact AI coroutine JoinGame callsite is wrapped;
unrelated AI calls retain the original function. The owned request receives its
current connection before the coroutine resumes, then JoinedGame only after
process membership/shared-world ownership has been checked. GameStarted resets
the service frame, so it is delivered once before that service's frames.
Frames must begin before waiting for AI Playing status: native AI first needs
its JoinArmy command processed and its simulated player/AI world available.

Normal completion retains mode4 and native winner/MatchData. Mode4 itself skips
reward UI. Response delivery uses the existing exact AccountService listener
exclusion; that listener still touches Steam inventory even for empty rewards.
Progression is unchanged; there are no fabricated currency/XP/rating awards.
Native shutdown owns AI disposal and world destruction. Only after the main
menu, idle human world, empty AI process list and zero AI world may roots go.
Returning to the deck editor automatically is not established by static evidence.
