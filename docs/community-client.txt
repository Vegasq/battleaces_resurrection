SOURCE AND OWNERSHIP
- community_wire.hpp: bounded versioned LE codec, strict UTF8, identity/enum/
  collection checks, positive request IDs and exact payload consumption.
- community_transport.cpp: welcome identity, directory/lobby revision and
  membership checks, bounded pending/event queues, ACK correlation and timeout.
  The socket decoder creates no managed objects. Presence and match WELCOME
  are separate states; community presence leaves assignedSeat=-1.
- community_native.cpp: Unity-thread object construction, canonical managed
  named handles, native manager discovery, deferred rooted request FIFO and
  original native Create/State/Closed handlers. CLR field barriers/constructors
  preserve native object ownership. Roots release only on the owned Unity thread;
  process shutdown does not call IL2CPP from a CRT/DllMain destructor.
- community_roster.cpp: native pool Take/Bind/Add and Clear/Release, with scoped
  outer row/model/child roots. FriendModel's evidenced small constructor is
  reconstructed without Steam presence/avatar work. The outer row observes
  its owned model normally; the child FriendVM remains unbound and receives
  binding setters plus UpdateAllBindings. All child actions/cosmetics and stale
  text are explicitly reset. Ordinary non-community callsites forward unchanged.
- community_invites.cpp: exact request/invitation correlation, deferred native
  reply credits, canonical incoming objects, exact-pointer sent cleanup, native
  clock anchoring and Party reconciliation. Interrupted completion roots survive
  until explicit reconnect settles outstanding native callbacks.
- community_popup.cpp: observer-owned native panel discovery, typed notification
  cross-check, deferred binding repaint, exact release and bounded native probes.
- community_match.cpp: exact pending Start/Ready ownership and attempt epochs,
  selected/frozen deck checks, narrow native Created/Join handoff, GameStart
  closure and same-connection match teardown/RETURN/restored native lobby.
  Match aborts use separate owned recovery, preserving the durable connection;
  native setup/loading/active/result boundaries are in native-custom-matches.txt.

Directory rows include self and busy players. The displayed status is fixed local
text; ASCII angle brackets in display names become fullwidth brackets because
both the native name label and its tooltip accept rich text. The canonical named
protobuf identity is unchanged. Native directory names are not inserted into a
global Steam list. Row/model ownership is registered before native binding and
removed on release; a failed unlisted row is released exactly once. Directory
rebuilds prune unused canonical cache roots, avoiding lifetime-long growth as
different profiles connect. Native lobby state retains the few needed identities.

All native lobby sends and responses are deferred until the originating native
call has stored its pending request. Snapshot payloads are applied in event
order, not by consulting only the latest eagerly decoded global snapshot.
Leave immediately releases the native manager. If Create is still pending,
its eventual ACK is consumed without calling the released manager, and queued
Leave reclaims the admitted server lobby. An unsent cancelled Create is dropped.
Another Create waits until departure ACK. Native state notifications are held
while a departure is queued. Ordinary Create responses check the retained native
request pointer, remove the adapter entry before native reentrant callbacks,
and keep the owner/response rooted until the callback returns.
