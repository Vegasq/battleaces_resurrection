The command creates sixteen bounded task units sequentially:three alternating
unprofiled one/two-core pairs and one separate instrumented pair per workload.
Each uses a random ba-cpu-bench-UUID.service identity, nonce-bearing Description,
AllowedCPUs, KillMode=control-group, Restart=no, UMask0077 and finite RuntimeMaxSec.
Preexisting units refuse. The inner coordinator verifies actual InvocationID,
ControlGroup, cgroup inode, effective hard cpuset and its actual CPU mask before
constructing any Wine backend. After CREATE and before close, retained owned
cgroup descriptors bind descendant/thread CPU-mask observations. Missing nested
cpuset interfaces are recorded as inheritance from the verified unit hard cap.
This scopes coordinator+guardian+Wine together; Windows worker-only affinity and
host-wide vCPU provisioning remain different experiments.
