Double-click the standalone BattleAces-Installer-RC1-103.exe. It contains the
complete patch runtime;no ZIP extraction,Python install or PowerShell policy
change is required. Alternatively,extract the full client ZIP and double-click
Install Battle Aces.exe. Setup Client.cmd opens that same native window.

1. Browse to the working folder containing Battle Aces.exe (supported build37822).
2. Enter the server IP,or leave it blank for offline play. Click Install / Update.
3. Wait for the installed message,then close the installer.
4. In the GAME folder,double-click Start Battle Aces.cmd for every later launch.

backs up local settings and restores the original starter selection on next

first. Uninstall client patch restores verified original game files and removes
the owned launcher/helper,keeping saves,config,recovery backups and cached runtime.

copying an already patched game with its profiles also copies its selected deck.

The game folder now contains its own verified Python/client runtime under
.battleaces-resurrection/client-runtime/. The downloaded installer/extracted
package is no longer needed for launching. Original game backups and personal
decks/cosmetics remain under .battleaces-resurrection;keep that directory.
Advanced settings,including display_name and server_port,are editable in
.battleaces-resurrection/client-config.json. Existing names/profiles are preserved
on update. Default server port:47623. No CA,certificate name,fingerprint or invite.
TLS encryption without certificate verification remains the explicit RC policy.
Install verifies local game content and may take several minutes on a slow drive.
Close the game before installing/updating. No original game assets are distributed.

BATTLE ACES RESURRECTION - VERIFIED CLIENT PATCH REFERENCE

Development preview for your own Windows x64 copy of Battle Aces build37822.
No original game files are included. Clean-PC and outside-network acceptance are
still pending. Extract this archive to a separate ordinary local folder. The
bundled Python runtime needs no installation; its license is under
program/runtime/LICENSE.txt. Run the command examples in Command Prompt (cmd.exe)

Use Start Client.cmd for local play and optional multiplayer. Double-click
BattleAces-Client.cmd to open Connection Setup. Use --help in a terminal for

  BattleAces-Client.cmd verify

Get the archive and SHA256 from a trusted project release. Keep program files

1. INSTALL OR RESTORE

Close the game. Keep an untouched recovery copy and patch a separate working copy.
The patcher accepts only supported original hashes, preserves originals under
.battleaces-resurrection/original, and rolls back replaced files on failure.
Installation also verifies all133 local AssetBundles (about6.7GB) against the
supported build's SHA256 values. This may take several minutes on a slow drive;
keep setup open while it finishes. No game assets are included in this package.
After verification, the patch changes the local catalogue's CRC settings so
Unity need not repeat full-bundle CRC validation at every load. Bundle files
remain unchanged. Ordinary launches check their fingerprints and rehash any
changed files; missing/corrupt content is refused. Reinstall to refresh the
verification after repairing your supported game files. A dry-run verifies the
same inputs without writing the catalogue, receipt or backups.

  BattleAces-Client.cmd install --game "<working game directory>" --dry-run
  BattleAces-Client.cmd install --game "<working game directory>"

If that working copy was patched before a managed original backup existed, add
--original "<verified original GameAssembly.dll>". Other unknown modifications
are refused. Never point install at your untouched recovery copy. Upgrades use
the new package's install command after closing the game and verifying originals.

To restore the original patched components:

  BattleAces-Client.cmd restore --game "<working game directory>"

The manifest and original backups stay available for inspection/reinstallation.
Restore does not erase your decks, personal configuration or saved preferences.
It also restores the exact original catalogue; bundle files are never rewritten.

2. START THE CLIENT / PLAY LOCAL AI

After installing the patch, select the game once:

  "Start Client.cmd" --game "<working game directory>"

This creates config/client.json with local defaults. Subsequent launches only
need a double-click on Start Client.cmd. If the package folder is directly inside
the patched game folder, its parent can be detected on first launch without
--game. Existing configuration is preserved. Edit display_name there to change
your player name for the next launch; JSON paths use doubled backslashes or
forward slashes. Keep the launcher console open while playing.

In a current source-built patch,optional local_profile defaults to "default".
It keeps native unit decks/options under the game's
.battleaces-resurrection/profiles/<key>/gameconfig-localuser.toml. Use different
keys,such as player_one and player_two,for two clients on this PC. Keys accept
1..48 lowercase letters,digits,underscores or hyphens,excluding reserved Windows
device names. One process per installation/profile is allowed. The patch leaves
the old Windows-user settings file untouched and does not automatically import
it. Existing frozen preview archives are not upgraded by a source checkout;
rebuild/install the matching helper before using this behavior.

The current source patch reports optional DLSS upscaling unavailable before
NVIDIA NGX initializes. The original renderer fallback and shutdown remain active;
this avoids a verified NVIDIA telemetry cleanup hang on the test machine. It
does not change system NVIDIA settings. Existing frozen archives are unchanged.

Open Edit Deck -> Try Deck vs AI. No server, CA, invite or server assets are needed.
Missing or invalid online settings leave local play available. Settings -> General -> AI
Difficulty offers Easy/Normal/Hard. The saved choice applies to the next match.
Normal is the first default. Manual launch has no automatic play or surrender.
Match-start feedback has passed native state checks; visual acceptance remains
open. Startup can take longer on a cold game installation. Ordinary launch enables
no scripted production, surrender, Continue or heavy diagnostic captures.
Current source candidates enable public1v1/2v2/2vAI and installed cosmetic
selection through Start Client. Public play uses local AI when no server is
configured/available,and server queues fill missing opponents after30s. Custom
is human-only. Ordinary-feature mode/team/fault and final package/manual checks
are still in qualification;see ordinary-player-client.txt in the source checkout.
Older frozen previews retain their own compatibility.json source/feature scope.

The older practice command and config/practice.example.json remain available for
the separately qualified standalone path. The normal Start Client uses one game
process for local practice,public play and optional Custom presence.

3. CONNECT TO YOUR FRIEND'S SERVER

Ask the host for its address, port, certificate name, public CA file and your
private invite file. Also get the SHA256 of that exact CA file through a trusted
channel. This is the whole-file SHA256, not a certificate thumbprint.

Double-click BattleAces-Client.cmd (or run its configure command). Choose your
working game folder; Install patch uses the same reversible installer above.
Enter your display name, the host's address/port and certificate name, then
browse to the CA and downloaded invite. Read fingerprint displays the selected
CA's file hash. Paste the host-supplied hash into its separate confirmation field.
Save connection validates the match, creates protected local copies under
config/private/, then writes config/client.json. It preserves the original
downloaded invite and prior settings if saving fails. It never changes Windows
certificate trust or weakens an existing file's permissions.

Test connection verifies TLS and authenticates your invite without launching a
game or joining a room. If it succeeds, Play multiplayer starts the patched game.
Unsaved changes must be saved before Test/Play. You may close the setup window
after launching; its separate transport process remains with the game. If the
window reports settings changed externally, close and reopen it before editing.

Keep the downloaded invite private. Once import and connectivity succeed, you
can remove that transfer file yourself. No token belongs in command arguments,
screenshots or public chat. A revoked invite requires a new file from the host.
Changing servers requires that host's CA/hash and invite; configure does not
download or silently accept certificates. Normal-account Windows private-file
qualification remains a release gate; see the source knowledge base.

Connection Setup accepts local schema3 defaults and saves enrolled schema2 JSON.
Start Client accepts both. The same file remains editable. Online fields may be
left blank for local play; actual connections still require verified trust and a
private invite. Fields are:
  game_directory   Full path to your patched working copy.
  server_host      The host's IPv4 address or DNS name.
  server_port      The host's TCP port, default47623.
  server_name      The DNS name or IP covered by the server certificate.
  ca_bundle        Local path to the trusted CA/public certificate.
  credential_file Local path to your private invite file.
  display_name     The name shown to other connected players.
  room             A shared normal-match room label, such as friends.

Relative file paths follow the config file's directory. Imported invite copies
must keep their protected owner/SYSTEM permissions. The example is a format
reference; for downloaded invitations, use setup to create the private copy.

If Start Client reports native save paths are too long,close the client,move the
patched working copy to a shorter local folder,and update game_directory in your
client config. Keep its .battleaces-resurrection folder to preserve saved profiles.

Equivalent checks/launch from a terminal:

  BattleAces-Client.cmd check

  BattleAces-Client.cmd launch

When using the launch command directly, keep that console open while playing:
it owns the secure transport. In the game,
Custom Game -> Invite Friend lists connected players. Invite the intended friend;
after acceptance, use the native Start/Ready flow. Normal Play uses the configured
room. A finished match should return through Continue. In-match reconnection is
not supported; a lost session requires returning to the menu/relaunching.

Use --config "<personal file>" after configure, check, launch or practice to choose
another config. The selected config's parent directory must already exist.
No automatic ready/surrender, heavy capture or telemetry audit is enabled in these
commands. Known telemetry entry points are patched; complete clean-profile and
error/reporter-path qualification is still pending. This preview is not a claim
that every analytics path has been eliminated.
