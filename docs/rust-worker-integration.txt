BATTLE ACES - N45 ISOLATED RUST DECODER WORKER INTEGRATION
Updated:2026-11-17UTC. Isolated integration qualified;default runtime stays Python.

SCOPE
Continue N44 by loading the Rust decoder into an explicitly opted-in native
Windows worker. The original simulation DLL,thread ownership,worker process,
request protocol and terminal-error/cleanup behavior are retained. Only state
decoding at the worker boundary changes. The Rust DLL returns strict JSON which
Python parses before the existing worker response is serialized. Whole-worker
measurements therefore include that conversion cost and normal pipe IPC.

The parent requires an absolute library path and exact SHA256,then checks the
worker's reported implementation,ABI version and loaded library identity. No
silent fallback is allowed. Normal launchers do not supply the experiment flag.
Standalone FFI validation also runs against a native Linux shared library;
native game worker integration currently requires Windows. This does not
recompile the original simulation DLL into a Linux binary.

BOUNDARIES
Rust ABI1 borrows snapshot bytes for one call and returns a pointer/length to
owned JSON. The Python adapter always releases a successful output allocation
through the same library. Decode/refusal statuses are explicit;unwinding panics
are caught. Invalid foreign pointers,double frees,allocator aborts and a hostile
library cannot be made safe by this ABI. Input<=16MiB and JSON<=64MiB;intermediate
decoded-map allocation still requires a production memory budget. Use only the
source-owned hash-bound library and owned diagnostic inputs.

QUALIFICATION
- Rust ABI controls:argument rejection,strict JSON,allocation/free and panic
  containment;clippy warnings-denied and formatting checks.
- Python controls:library identity/ABI,buffer release on all paths,no fallback,
  parent/worker handshake and synthetic/backend restrictions.
- Actual FFI comparison on authored fixtures and all retained native snapshots
  from N44,in both full and summary modes. Exact finite floats/negative0 match.
- Three alternating Python/Rust pairs per retained native workload. Recorded
  AI commands are replayed,not regenerated. Every observable state at every
  frame must match its journal;this does not cover hidden DLL state.
- Bind source/library/journal/assets/capture identities before and after;
  require ordinary worker exit0,closed threads and no worker failure.
- Compare step RPC and startup per same-machine pair. Unpaced RPC measurements
  are worker cost evidence,not Internet20Hz publication or player acceptance.
