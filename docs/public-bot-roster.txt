Purpose
Public1v1 fallback must use varied original-style decks/names/portraits and a
random supported difficulty. Try Deck retains its explicit practice difficulty.
The shipped data supplies these inputs, but the retired server's complete random
selection algorithm is not present in this investigation. A replacement selection
policy must be identified as new behavior and tested in the actual game.

Implementation and remaining proof
Load installed mode-specific inputs, select a profile-compatible deck and clone
it; snapshot a distinct bot handle, name and cosmetics once per match. Keep that
snapshot stable through results. Apply a separately defined random difficulty
policy for public fallback; retain the user's chosen practice level for Try Deck.
Original RNG/seed, duplicate-name handling, rating interpolation, A/B cohorts and
live overrides remain unknown. Native filtering/localization, portraits/banners,
all four public1v1 profiles and result/rematch propagation need runtime testing.
Bot cosmetics selection does not implement the separate all-player-cosmetics
unlock/persistence requirement.
