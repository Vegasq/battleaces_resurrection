Experimental local public1v1 implementation (not default public matchmaking)
native_tables.cpp and public_bots.cpp load the installed inputs asynchronously.
The replacement policy chooses an enabled opponent profile by authored weight,
then one of its Type2 presets uniformly. It clones the shared deck and chooses an
English installed name plus allowed portrait/banner. Names exclude the human and
the immediately preceding bot. English-only selection is a documented current
policy, not a reconstruction of the retired server's region/language RNG.
Public difficulty independently chooses Easy/Normal/Hard uniformly and applies
the already supported practice strength modifiers; tactics remain the selected
public profile. Try Deck's saved difficulty remains unchanged. BCrypt rejection
sampling avoids modulo bias. No recovered roster contents are embedded in source.
The frozen bot identity/portrait/banner is carried in ArmyConfig and JoinArmy;
the original JoinArmy serializer omits the latter two fields without this step.

The shared local AI lifecycle accepts mode1 through -public-ai-experimental.
Normal package launch does not set that flag: server queue/30-second arbitration,
partial human groups, team modes and their race cases remain separate unfinished
requirements. Custom does not use this path. -public-ai-smoke is also opt-in and
invokes the real active mode1 button; a bounded profile override is test-only.
tools.verify_public_ai runs the real unified launcher with no server/CA/invite,
records native combat and results, and forcibly reaps its owned hidden process.
This harness does not establish mouse input, visible name/avatar rendering,
normal Quit, process-wide traffic absence or public online queue correctness.
