RESULT
AssetMemoryManager scene unload is separate from205's scheduler cancellation.
For a running scene operation,Addressables constructs a chain operation instead
of immediately entering InternalUnloadScene. Both reviewed chain callbacks later
call InternalUnloadScene. This establishes a deferred release path,not a safe
way to cancel an indefinitely pending scene load. No production code changed.
