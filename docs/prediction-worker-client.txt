PURPOSE
Run the original native simulation in one owned local worker. Unity calls typed
API shims over inherited pipes;native pointers never cross the process boundary.
This gives checkpoint capture/replay a permanent owner,independent of Unity's
threads and CRT roots. It is a transport foundation,not installed prediction.
The normal patch output and launchers remain unchanged. Explicit owned probes
use the optional GetProcAddress hook and -prediction-native-worker-probe.

skipped by its original loader. All24 recovered raw ABI wrappers are separately
authored-tested;the crash API is never invoked by these gameplay checks.
