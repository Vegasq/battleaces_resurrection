NATIVE MODIFIER CONTRACT
AIProfile.AIConfigDefinition._cheatModifiersByRating has one row for each choice.
Its CheatModifier.ToProto (original GameAssembly RVA37b67c0) produces Q32 integers
using the original float conversion, so nominal decimal values have native float
rounding. CommonPb.AICheatModifier fields are resourceMultiplier_,
armyDamageMultiplier_ and armyHealthMultiplier_. This object is not cast to the
different GamePb.ArmyModifiers type.

Before encoding the owned practice GameConfig, the adapter clones bot army1's
existing ArmyModifiers (or explicitly initializes resource unity if absent).
It composes resourcingMultiplier_ using positive bounded Q32 integer arithmetic.
One fresh-key ModifierConfig is appended to armyBuffs_, preserving existing
global and army buffs. The key excludes every existing global/army modifier key.
Attributes damage1/health4 use multiplicative kind1; label mutations remain empty.
The original Simulation.dll importer defaults resource unity only when modifiers
are absent. Attribute application stores modifiers per attribute/kind/key; a
duplicate key replaces a previous modifier. Recalculation directly multiplies
the supplied Q32 factor, without converting it to a delta from unity.
