Changes
- The native client and server GUI installers create a current-user desktop
  shortcut after a successful Install / Update action. The client shortcut
  targets the installed Start Battle Aces.cmd;the server shortcut targets the
  installed Start Server.exe. The working directory is the installed folder.
  An existing same-name shortcut without this installer's description marker
  is preserved and a warning is shown. A shortcut error does not undo a
  completed game/server installation.
- A new client install prefills server IP134.209.176.39. Selecting a game folder
  with an existing client-config.json loads its saved server_host instead.
  Manual edits,including clearing the IP for offline play,are retained.
- The game helper SHA256 is unchanged from rc1.7:
  e5f8201edadf0c6852464e36b813f0ab0beb8523769013207931e7306f6683ac.
  Game build,game protocol3,community protocol2 and asset format1 are unchanged.
  The original game files and private state are not distributed.
